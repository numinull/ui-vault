# UI Vault

A personal collection of UI components with glass styling, hover demonstrations, isolated previews and copyable code.

Open `index.html` locally, or serve this folder as a static website. No build step is required.

## Adding components

Edit the `items` array inside `index.html`. Each component has an ID, name, category, tags, HTML, CSS and an optional JavaScript string. The `art` field supplies a trusted decorative thumbnail. Keep identifiers unique and use an existing collection category. The frosted button styles are defined separately in `frostedCSS`.

Components are stored in this file, not in browser storage. The app has no accounts, upload service or editing interface.

## Previews

Detail previews run in sandboxed iframes with external assets restricted. Gallery hover effects are decorative demonstrations. Review third-party code and its licence before adding it.

## GitHub Pages

For branch-based deployment, select the main branch and root folder in the repository's Pages settings.
